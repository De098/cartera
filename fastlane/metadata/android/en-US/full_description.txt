Cartera keeps your membership, loyalty and library cards, tickets and boarding passes on your phone, with their code ready to show: no account, no server and no internet permission. Your data never leaves the device. The app is in Spanish.

<b>Cards with a code</b>
• Name, number, colour, note and favourites. A searchable list: favourites first, then the ones you use most.
• QR, EAN-13, EAN-8, UPC-A, Code 128, Code 39, Aztec, PDF417 and Data Matrix codes.
• Opening a card shows a big code with the number below, full screen brightness and the screen kept on. Closing it restores everything.

<b>Three ways to add a card</b>
• Scan the code with the camera (the permission is only asked at that moment).
• Read the code from a photo or screenshot in your gallery.
• Type the number and choose the type.

<b>Tickets and passes</b>
• With the event date and time, an attachment (image or PDF) and/or its code.
• A reminder on the day of the event and a configurable earlier one (for example, one day before).
• Once the event is over they are archived automatically; you can restore or delete them.

<b>Tickets that fill themselves in</b>
• Scanning an airline boarding pass (IATA) gets the flight, origin, destination and day; for UIC train tickets (Aztec), the date, time and stations the code carries.
• It fills in the form without saving and tells you what it found. If the code has no date (e.g. Renfe tickets), it asks whether it is a ticket and then asks for the day and time.
• "View code content" and "Recognise date" on every card.

<b>Expiry dates</b>
• Any card can have an expiry date, with configurable reminders (by default 30 days before and on the day).
• "Expires soon" and "Expired" badges.

<b>Also</b>
• Favourites widget: tap one and its code opens.
• Home screen shortcut to a single card.
• Backup to a .zip file.

<b>Import from other apps</b>
• Catima (its .zip or .csv backup, without a password), Loyalty Card Keychain, Apple Wallet passes (.pkpass, also when opened from an email or the browser) and any .csv file with a header row.
• The format is detected automatically. When done you see how many cards were imported, how many were already there and how many came without a drawn code.

Light, high-contrast theme. Free software (GPL-3.0).
